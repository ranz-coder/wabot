Quick Installation (Base Version)

Run these commands on your terminal to clone, configure, and boot the bot instantly.

bash
$git clone https://github.com/neoxr/neoxr-bot.git
$cd neoxr-bot
$npm install
# Edit your configurations inside config.json or env variables
$node .
